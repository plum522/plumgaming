このカテゴリでは、トラックとトレーラーの種類、カスタマイズについて解説します。

トラックもトレーラーもこのゲームにおいて必須の要素で、ゲームをより簡単に進めたり楽しむために、トラックやトレーラーについてよく知ること、うまく使いこなすことがとても重要です。
このカテゴリでは、基本的な要素から攻略に活かすための知識まで幅広く取り扱っています。
ゲーム内に登場するすべてのトラックとトレーラーの特徴、それぞれの比較もしています。
