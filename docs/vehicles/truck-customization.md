# トラックのカスタマイズ

トラックはカスタマイズで多くの要素を変更できますが、<br>
全車統一の項目もありますが一部項目は、<br>
カスタマイズできる範囲がトラックによって違います。

  
| カスタマイズ項目 | 全車統一 |
| --- | --- |
| シャーシ | × |
| キャビン | × |
| エンジン | ◯ |
| ギアボックス | × |
| エクストラ | × |
| 付属品 | × |
| ホイール | ◯ |
| 色と肌(スキン) | ◯ |
