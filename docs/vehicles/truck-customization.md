# トラックのカスタマイズ

トラックはカスタマイズで多くの要素を変更できますが、<br>
カスタマイズできる範囲はトラックによって違います。<br>
カスタマイズの制限や違い一覧です。<br>
全車統一のカスタマイズ項目は、全車で同じ部品が使えます。
  
| カスタマイズ項目 | 全車統一 | 制限有り車 |
| --- | --- | --- |
| シャーシ | × | Moon THA・Fiora Fi-Man |
| キャビン | × | 複雑なため省略 |
| エンジン | ◯ | - |
| ギアボックス | × | 複雑なため省略 |
| エクストラ | × | 複雑なため省略 |
| 付属品 | × | 複雑なため省略 |
| ホイール | ◯ | - |
| 色と肌(スキン) | ◯ | - |
