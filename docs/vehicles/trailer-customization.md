# トレーラーのカスタマイズ

トレーラーは以下のカスタマイズができます。

- 色と肌(スキン)
- ホイール
- シャーシ

___
## スキン適用不可の車両
  
- Log Trailer
- Gooseneck
- Fixed Lowbed
- Lowbed
- Oversize

これら以外の16台はスキン適用できます。
色設定はすべての車両で可能です。

___
## ホイールカスタマイズ

### NW#1・NW#2を切り替えて使える車両

- Curtain Side
- Curtain Side 2
- Closed Box
- Refrigerated
- Double Tarp
- Double Refrigerated
- Flat Bed
- Brick Trailer
- Log Trailer
- Gooseneck
- Tanker
- Cistern Trailer
- Cement Bulker
- Mixer
- inLoader
- Scrap Trailer
- Tipper Trailer

### HWのみに対応する車両

- Open
- Double Open
- Fixed Lowbed
- Lowbed
- Oversize

___
## シャーシカスタマイズ対応の車両

| トレーラー名 | シャーシ |
|---|---|
| Double Tarp | Short / Medium / Long |
| Double Refrigerated | Short / Medium / Long |
| Fixed Lowbed | 3x0 / 4x0 / 5x0 / 6x0 |
| Lowbed | 6x0 / 8x0 |
| Oversize | 2x0 / 3x0 / 3x1 / 4x2 / 5x3 |

これら以外の16台はすべてシャーシの変更ができません。

> ⚠️Oversizeは5x3にアップグレードすると、Zurich・Munich・Stuttgartの3都市でしかジョブが受けられません。
> 5x3以外であれば他の都市でもジョブが可能なため、戻せば大丈夫です。<br>
> ⚠️ Oversize(5x3)は全長が他のトレーラーの2倍近いため、
> 一部の道路や積み込みで運転に苦労することがあります。
> 運転には特段の注意が必要です。
