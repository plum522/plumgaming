# トレーラーのカスタマイズ

トレーラーは以下のカスタマイズができます。

- 色と肌(スキン)
- ホイール
- シャーシ

特に「色とスキン」の変更はかなり見栄えが変わるため、大人気かつおすすめのカスタマイズです。

## スキン適用不可の車両
  
- Log Trailer
- Gooseneck
- Fixed Lowbed
- Lowbed
- Oversize

これら以外の16台はスキン適用できます。
色設定はすべての車両で可能です。

## ホイールカスタマイズ

### NW#1・NW#2を切り替えて使える車両

- Curtain Side
- Curtain Side 2
- Closed Box
- Refrigerated
- Double Tarp
- Double Refrigerated
- Flat Bed
- Brick Trailer
- Log Trailer
- Gooseneck
- Tanker
- Cistern Trailer
- Cement Bulker
- Mixer
- inLoader
- Scrap Trailer
- Tipper Trailer

### HWのみに対応する車両

- Open
- Double Open
- Fixed Lowbed
- Lowbed
- Oversize

## シャーシカスタマイズ対応の車両

| トレーラー名 | シャーシ |
|---|---|
| Double Tarp | Short / Medium / Long |
| Double Refrigerated | Short / Medium / Long |
| Fixed Lowbed | 3x0 / 4x0 / 5x0 / 6x0 |
| Lowbed | 6x0 / 8x0 |
| Oversize | 2x0 / 3x0 / 3x1 / 4x2 / 5x3 |

これら以外の16台はすべてシャーシの変更ができません。
