# 操作方式の選び方

Truckers of Europe 3では、主に４つの操作方式から選べます。

## 操作方式の種類

1. **傾き操作**：スマートフォン本体を傾けてハンドルを切る方式
2. **ボタン操作**：画面上のボタンをタップして操作する方式
3. **ステアリングホイール**：画面上のハンドルを指でなぞって操作する方式
4. **外部コントローラー**：Bluetoothなどで接続したゲーム用コントローラーを使い操作する方式。<br><br>
   ※iPhoneとandroidの両方でSwitchやPlay StationやXboxなど多くのコントローラーが使用できます

## おすすめの選び方

- 初めてプレイする場合は、デフォルト設定で直感的な操作性のタッチステアリング操作がおすすめです。
- 細かい操作をしたい場合は、ボタン操作がおすすめです。
- テレビやモニターに画面を映して操作したい場合は、外部コントローラーがおすすめです

> ⚠️ 外部コントローラーは全てのスマホやコントローラーで使用できるとは限りません。

## まとめ

それぞれの操作方法に良さがあるのでぜひお好みの操作方法を見つけてプレイを楽しんでください！
