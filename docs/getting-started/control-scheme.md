# 操作方式の選び方

Truckers of Europe 3では、主に４つの操作方式から選べます。

## 操作方式の種類

1. **ステアリングホイール**：画面上のハンドルを指でなぞって操作する方式
2. **ボタン操作**：画面上のボタンをタップして操作する方式
3. **傾き操作**：スマートフォン本体を傾けてハンドルを切る方式
4. **外部コントローラー**：Bluetoothなどで接続したゲーム用コントローラーを使い操作する方式。
   
   ※iPhoneとandroidの両方でSwitchやPlay StationやXboxなど多くのコントローラーが使用できます

## おすすめの選び方

- 初めてプレイする場合→デフォルト設定のタッチステアリング
- 細かい操作をしたい場合→ボタン
- 長時間プレイしたい場合→コントローラー
- 直感的に操作したい場合→傾き操作
  
> ⚠️ 外部コントローラーは全てのスマホやコントローラーで使用できるとは限りません。

## まとめ

それぞれの操作方法に良さがあるのでぜひご自分でお好みの操作方法を見つけてプレイを楽しんでください！
