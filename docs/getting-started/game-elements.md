# ゲーム内要素

このゲームに存在する基本的なシステム要素を紹介します。

## 燃料（ガソリン）

運転において欠かせない要素。<br>
500kmごと程度にガソリンスタンドで給油するのがおすすめ。<br>
給油は広告視聴で無料にできる。

## ガソリンスタンド

ゲーム内で必須のガソリンを給油できる<br>
ほぼ全ての都市に存在する。<br>
高速道路にも存在する。

## 睡眠

このゲームにはゲーム内時間で毎日最大6時間睡眠が必要です。
眠らずに長時間運転していると眠気で視界が真っ暗になります。
事故につながるため、できれば画面下にある睡眠のゲージが0になる前に睡眠しましょう。
ガソリンスタンド、ガレージ、高速道路の道端にあるベッドのマークの場所で睡眠できます。

## 高速道路の料金所

高速道路を走ると1回は通ることになる。<br>
料金は€100~150、車両の重量によって金額が異なる。

## フェリー

マップ一部に存在する。<br>
料金は€500、広告視聴で無料にできる。<br>
Tremola (トレモラ)🇨🇭に行く道の間にある。
