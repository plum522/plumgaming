# 初めてのジョブ

準備が整ったら、実際に最初のジョブ（配送の仕事）に  
挑戦してみましょう。  
ここでは最短の手順だけを説明します。

## 手順

1. アプリを開いた直後の画面の場合はまず右下の「ドライブ」をタップ。
2. 右上の一時停止ボタンをタップ。
3. 画面左側の「就職する」をタップ
4. ジョブ一覧の並び順を「距離が短い順」にして一番短いものを選ぶ
   >どんな距離も経験値は同じため序盤は短めがおすすめ
6. 左上のナビを参考に積荷場所に向かいトレーラーを連結する
   >難しい場合は広告でスキップするのがおすすめ
7. 左上のナビを参考に配達先まで運搬しましょう。
8. 配達先に着いたらトレーラーを駐車枠に駐車すると終わりです。
   >駐車はかなり難しいため広告でスキップが特におすすめ

## お疲れ様でした！

これで最初のジョブは完了です。  
ジョブについてさらに詳しく知りたい方は  
[ジョブ（配送）](/docs/delivery/)を参照してください。
