## Engine

This has the greatest impact on the truck’s performance. <br>
The more power, the better. <br>

___
## Gearbox

This improves top speed and makes starting and accelerating easier. <br>
It’s recommended to upgrade this along with the engine, especially when handling heavy cargo. <br>

### Retarder

Mainly used on long downhill slopes. <br>
It slightly reduces speed while active. <br>
It’s not essential in the game, but it’s convenient to have. <br>
For example, if it’s labeled “Retarder 3,” it’s a retarder with three levels of intensity. <br>
If no specific label is provided, it has only one level.

___
## Extras

<img src="/assets/images/vehicles/truck/extras.png" width="350"><br>
These include mud flaps and body covers. <br>
While they don’t affect performance, they significantly change the vehicle’s appearance, so they’re recommended customizations.

___
## Accessories

<img src="/assets/images/vehicles/truck/accessories.png" width="350"><br>
These include aftermarket lights and beacons (warning lights).<br>
Like Extras, these are cosmetic customizations that don’t affect performance.

___
## Wheels

<img src="/assets/images/vehicles/truck/wheel.png" width="350"><br>
<img src="/assets/images/vehicles/truck/all-wheel.png" width="350"><br>
You can change the wheels on all trucks. <br>
There are three types: Type 1, 2, and 3. <br>
In fact, each type seems to have different performance characteristics; we recommend Type 2, which is suitable for both paved roads and off-road use. <br>

___
## Color and Skins

The cost to change these is €750 for all trucks. <br>
This is recommended for recreating real-world vehicles. <br>
