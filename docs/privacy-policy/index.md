# プライバシーポリシー

## 広告の配信について

当サイトでは、第三者配信の広告サービス（Google AdSense）を利用しています。このような広告配信事業者は、ユーザーの興味に応じた広告を表示するためにCookieを使用することがあります。

## アクセス解析ツールについて

当サイトでは、Cloudflare Web Analyticsを利用しています。このツールはCookieを使用せず、個人を特定する情報を収集しません。

## お問い合わせフォームについて

お問い合わせフォームで送信された内容（お名前・メールアドレス・お問い合わせ内容）は、回答の目的にのみ利用し、第三者に提供および公開することはありません。

## 免責事項

当サイトはゲーム開発元公式の制作ではなく、当サイトの製作者もゲーム開発元とは無関係です。<br>
そのため、当サイトの情報は可能な限り正確な情報を掲載するよう努めていますが、正確性や安全性を保証するものではありません。<br>
また、当サイトに掲載している画像類は全て著作権法および他者のプライバシーを遵守した上で掲載しています。<br>
他者のプライバシーが含まれる画像および、他者の画像を無断で掲載することは一切ありません。
